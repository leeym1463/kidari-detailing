## 이 템플릿 사용법

1. 이 파일을 복사해서 `src/content/cases/` 폴더 안에 새 파일명으로 저장하세요.
   파일명이 곧 URL이 됩니다. 예: `avante-fm-gwangtaek-20260315.md` → `/cases/avante-fm-gwangtaek-20260315`
2. 위 frontmatter(`---`로 둘러싸인 부분)의 값을 실제 시공 내용으로 바꿔주세요.
3. `draft: true`를 `draft: false`로 바꾸면 그때부터 목록/사이트맵에 노출됩니다.
4. 아래 본문에는 실제 작업 과정과 결과를 자유롭게 서술하면 됩니다. 첫 문단은
   "이 시공사례가 무엇인지"를 1~2문장으로 요약하는 문장으로 시작하는 것을 권장합니다
   (사이트 다른 페이지와 동일한 원칙 — AI 검색엔진이 이 문장만 인용해도 답이 되도록).

## 본문 작성 가이드 (예시)

시공 전 상태를 구체적으로 설명하고, 어떤 진단을 거쳐 어떤 공정을 선택했는지, 작업 중
특이사항이 있었는지, 시공 후 결과가 어땠는지 순서로 쓰면 소비자가 이해하기 쉽습니다.

사진이 있다면 Markdown 이미지 문법(`![설명](/images/cases/파일명.jpg)`)으로 추가할 수
있습니다. 이미지 파일은 `public/images/cases/` 폴더에 넣어주세요.
